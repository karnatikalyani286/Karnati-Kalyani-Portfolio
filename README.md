# Kalyani Karnati Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` - website structure and content
- `style.css` - design and responsive layout
- `script.js` - mobile menu, rotating role text, reveal animations and footer year

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a repository named `yourusername.github.io`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open repository Settings -> Pages.
5. Select the main branch as the source.
6. Your site will be available at `https://yourusername.github.io`.

Replace the placeholder project cards with real projects as you complete them.
